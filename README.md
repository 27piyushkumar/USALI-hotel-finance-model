# PiyAdra Hotel – USALI-Based Hotel Finance & Accounting Model

Developed as a portfolio project demonstrating hotel finance, accounting, financial reporting, and USALI implementation using Microsoft Excel.

A comprehensive hotel finance and accounting model developed in Microsoft Excel for a 150-room luxury city hotel, following the Uniform System of Accounts for the Lodging Industry (USALI).

## Project Overview

This project demonstrates how hotel operating assumptions are transformed into complete financial statements through a structured accounting workflow.

The model integrates operational planning, departmental reporting, journal entries, general ledger posting, trial balance preparation, financial statements, dashboards, and internal accounting controls into a single Excel workbook.
